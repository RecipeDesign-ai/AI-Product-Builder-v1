Why this product

기존 To-do 앱과 다른 점

일반 To-do 앱

  • 사용자가 앱을 다시 열어야 확인함
  • 리마인더가 약하고 수동적임
  • 완료 전환보다 기록 저장에 초점

Focus Ping

  • 실행 시점에 메시지가 사용자에게 직접 도착
  • 채널 우선순위와 재알림으로 행동을 유도
  • 완료, 미루기, 실패 로그까지 수집

System flow

서비스 작동 구조

01

Input

사용자가 할 일, 시간, 채널을 입력합니다.

02

DB

할 일과 발송 예약 정보가 저장됩니다.

03

Scheduler

정해진 시간에 맞춰 큐 작업이 생성됩니다.

04

Notification

SMS, 이메일, 알림톡으로 메시지가 전송됩니다.

05

Feedback
